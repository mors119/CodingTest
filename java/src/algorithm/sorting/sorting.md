# 정렬 알고리즘 정리

- Bubble = 단순 교환
- Counting = 개수 세기
- Heap = 트리 기반 선택
- Merge = 나누고 합치기
- Quick = pivot 분할
- Shell = 간격 줄이기

## 1. Bubble Sort (버블 정렬)

- **시간 복잡도**
  - 평균: O(n²)
  - 최악: O(n²)
- **공간 복잡도**: O(1)
- **특징**
  - 인접한 두 값을 비교해서 교환
  - 한 번 순회할 때마다 가장 큰 값이 뒤로 이동
- **개념**

```
계속 옆이랑 비교하면서 큰 값을 뒤로 밀어냄
```

---

## 2. Counting Sort (계수 정렬)

- **시간 복잡도**
- 평균: O(n + k)
- **공간 복잡도**: O(n + k)
- **특징**
- 값의 범위(k)가 작을 때 매우 빠름
- 비교 없이 개수를 세서 정렬
- **개념**

```
각 숫자가 몇 번 나왔는지 세서 위치를 계산
```

---

## 3. Heap Sort (힙 정렬)

- **시간 복잡도**
- 평균: O(n log n)
- 최악: O(n log n)
- **공간 복잡도**: O(1)
- **특징**
- 완전 이진 트리 기반 (힙)
- 최댓값을 계속 꺼내면서 정렬
- **개념**

```
힙을 만들고, 루트(최대값)를 하나씩 뒤로 보냄
```

---

## 4. Merge Sort (병합 정렬)

- **시간 복잡도**
- 평균: O(n log n)
- 최악: O(n log n)
- **공간 복잡도**: O(n)
- **특징**
- 분할 정복
- 안정 정렬
- **개념**

```
반으로 나누고 → 각각 정렬 → 다시 합침
```

---

## 5. Quick Sort (퀵 정렬)

- **시간 복잡도**
- 평균: O(n log n)
- 최악: O(n²)
- **공간 복잡도**: O(log n) (재귀 스택)
- **특징**
- pivot 기준으로 분할
- 매우 빠르지만 최악 케이스 존재
- **개념**

```
pivot 기준으로 작은 그룹 / 큰 그룹으로 나눔
```

---

## 6. Shell Sort (셸 정렬)

- **시간 복잡도**
- 평균: O(n^1.3 ~ n^1.5)
- 최악: O(n²)
- **공간 복잡도**: O(1)
- **특징**
- 삽입 정렬 개선 버전
- 간격(h)을 줄여가며 정렬
- **개념**

```
멀리 있는 값부터 먼저 정렬 → 점점 좁혀서 정렬
```

---

# 📊 전체 비교 요약

| 정렬     | 시간복잡도         | 공간복잡도 | 특징               |
| -------- | ------------------ | ---------- | ------------------ |
| Bubble   | O(n²)              | O(1)       | 단순, 느림         |
| Counting | O(n+k)             | O(n+k)     | 범위 작으면 빠름   |
| Heap     | O(n log n)         | O(1)       | 안정적, 트리 기반  |
| Merge    | O(n log n)         | O(n)       | 안정 정렬          |
| Quick    | O(n log n) / O(n²) | O(log n)   | 빠르지만 최악 존재 |
| Shell    | O(n^1.3~1.5)       | O(1)       | 삽입정렬 개선      |
